# Predictive-Sales-Forecasting-Project

## Introduction
The purpose of this project is to use PowerBI to create a data model capable of projecting a company's sales data. I will be generating accurate forecasts on their sales data to help with resource planning, business insights and risk mitigation. Throughout this project I will be using data analysis to analyze sales performance, gain insight on different parts of the company and support data-driven decisions for the business.  
PowerBI will be used to create interactive visualizations that will help the audience understand key trends, hidden patterns and make their own data-driven decisions.
